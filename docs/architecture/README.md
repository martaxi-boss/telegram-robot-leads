# Architecture

This directory will represent the **current approved architecture**, not speculative research.

Current status: **no Architecture Baseline yet**.

During discovery, alternatives belong in `../research/`. Once decisions are validated and accepted, architecture views can be promoted here.

Planned coverage, only as needed:

- system context (C4 Context);
- containers/services and responsibilities (C4 Container);
- critical components where justified;
- runtime/sequence views for critical flows;
- data model;
- integrations/contracts;
- security/trust boundaries;
- deployment/infrastructure;
- quality attributes and constraints.

Architecture documents are living current-state records. Decision history belongs in `../decisions/`.
