# Architecture Decision Records

ADRs preserve material project decisions and their rationale.

## Rules

- One material decision per ADR.
- Status: `Proposed`, `Accepted`, `Superseded`, or `Deprecated`.
- Accepted ADRs are historical records; do not silently rewrite their original rationale.
- When a decision changes, create a new ADR and link both records with `Superseded by` / `Supersedes`.
- Link supporting research/evidence/experiments.
- Record consequences and risks, including negative trade-offs.

Use `../templates/adr.md`.
