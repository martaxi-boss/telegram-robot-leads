# Evidence & Experiments

This area preserves the material basis for project conclusions.

## Evidence (`EV-xxx`)

Record primary/official documentation, measurements, provider/API facts, standards or other sources materially used in research/decisions.

Include source, access date, finding, scope/limitations, confidence and linked research/decisions.

## Experiments (`EXP-xxx`)

Record PoCs and empirical tests with objective, environment, procedure, expected result, actual result, observations and conclusion.

A failed or inconclusive experiment is still valuable evidence and must not be erased.

Use the templates in `../templates/`.
