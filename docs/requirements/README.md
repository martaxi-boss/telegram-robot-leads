# Requirements

This directory will contain accepted project requirements once they are elicited and validated.

Use stable IDs `REQ-xxx` and distinguish at least:

- functional requirements;
- quality/non-functional requirements;
- security requirements;
- operational requirements;
- constraints and assumptions where relevant.

A requirement should state the need without prematurely embedding a technical solution unless the solution itself is a fixed constraint.

Current status: requirements discovery is pending/in progress; no final requirement baseline is declared yet.
